# Лабораторная работа № 1. Проверка закона Ома для участка цепи

Дисциплина: Электротехника и электроника.
Продолжительность: 2 академических часа.

## 1. Цель работы

Экспериментально проверить закон Ома для участка цепи, построить вольт-амперную характеристику (ВАХ) резистора, определить его сопротивление двумя способами (по отдельным измерениям и методом наименьших квадратов) и оценить погрешность результата.

## 2. Оборудование

1. Регулируемый источник постоянного напряжения 0...12 В.
2. Резистор МЛТ-0,5 номиналом 100 Ом (допуск ±5 %, допустимая мощность 0,5 Вт).
3. Цифровой мультиметр в режиме амперметра: предел 200 мА, разрешение 0,1 мА, погрешность ±(1,2 % + 2 единицы младшего разряда).
4. Цифровой мультиметр в режиме вольтметра: предел 20 В, разрешение 0,01 В, погрешность ±(0,5 % + 1 единица младшего разряда).
5. Ключ и соединительные провода.

## 3. Краткие теоретические сведения

Закон Ома для участка цепи: сила тока I прямо пропорциональна напряжению U на участке и обратно пропорциональна его сопротивлению R:

I = U / R.

Для линейного резистора ВАХ, то есть зависимость I(U), является прямой, проходящей через начало координат. Угловой коэффициент этой прямой k = ΔI / ΔU = 1 / R, поэтому сопротивление можно найти как R = 1 / k.

Мощность, рассеиваемая на резисторе, P = U · I = U² / R. Чтобы резистор не перегрелся, мощность не должна превышать 0,5 Вт. Для резистора 100 Ом это ограничивает напряжение величиной U_max = √(P · R) ≈ 7 В, а ток величиной I_max ≈ 70 мА.

Амперметр включают в цепь последовательно с резистором, вольтметр подключают параллельно резистору. Внутреннее сопротивление амперметра должно быть много меньше, а сопротивление вольтметра много больше сопротивления резистора. Тогда приборы почти не искажают режим цепи.

## 4. Порядок выполнения работы

1. Собрать электрическую цепь: источник, ключ, амперметр и резистор соединить последовательно, вольтметр подключить параллельно резистору.
2. Установить регулятор источника в нулевое положение. Предъявить собранную схему преподавателю.
3. Замкнуть ключ и, плавно увеличивая напряжение от 0,5 до 7,0 В с шагом 0,5 В, записать показания вольтметра U и амперметра I в таблицу 1.
4. Повторить измерения при уменьшении напряжения (обратный ход) для проверки воспроизводимости результатов.
5. Установить регулятор в нулевое положение, разомкнуть ключ, выключить источник.

Таблица 1. Результаты измерений: номер опыта, U (В), I (мА), R = U / I (Ом).

## 5. Обработка результатов

1. Для каждого опыта вычислить сопротивление R_i = U_i / I_i (ток перевести в амперы).
2. Найти среднее значение R_ср = (1/n) · ΣR_i.
3. Найти среднее квадратическое отклонение среднего S = √(Σ(R_i - R_ср)² / (n(n - 1))).
4. Найти доверительную границу случайной погрешности ΔR = t · S, где t(P, n - 1) обозначает коэффициент Стьюдента при доверительной вероятности P = 0,95.
5. Построить ВАХ I(U) и провести аппроксимирующую прямую методом наименьших квадратов (МНК). По угловому коэффициенту найти R = 1 / k.
6. Рассчитать относительную погрешность ε = ΔR / R_ср · 100 % и сравнить результат с номиналом резистора с учетом допуска ±5 %.
7. Записать результат в виде R = (R_ср ± ΔR) Ом, P = 0,95.

## 6. Требования техники безопасности

- Собирать и изменять схему только при выключенном источнике.
- Не превышать напряжение 7 В, иначе резистор перегреется.
- При появлении запаха гари немедленно разомкнуть ключ и сообщить преподавателю.
